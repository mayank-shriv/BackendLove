### Frameworks and Dependencies

- **Node.js**: JavaScript runtime environment.
- **Express.js**: Web application framework for building the API.
- **MongoDB & Mongoose**: Database and ODM used for data modeling and implementing middleware (hooks) for password hashing.
- **jsonwebtoken (JWT)**: Used for secure user authentication and authorization.
- **bcryptjs**: Used for hashing and comparing passwords within Mongoose hooks.
- **dotenv**: For managing environment variables.
- **cookie-parser**: Middleware for handling HTTP cookies.
