### Technology Stack & Dependencies

| Name | Category | Usage |
| :--- | :--- | :--- |    
| **Node.js** | Runtime | JavaScript runtime environment. |
| **Express.js** | Framework | Fast, unopinionated, minimalist web framework for Node.js. |
| **MongoDB** | Database | NoSQL database for storing application data. |
| **Mongoose** | ODM | Object Data Modeling library for MongoDB and Node.js. |
| **bcrypt** | Security | Library for hashing passwords. |
| **jsonwebtoken (JWT)** | Security | Standard for securely transmitting information between parties as a JSON object (used for auth). |
| **cors** | Middleware | Middleware to enable Cross-Origin Resource Sharing. |
| **cookie-parser** | Middleware | Parse Cookie header and populate `req.cookies`. |
| **dotenv** | Configuration | Loads environment variables from a `.env` file into `process.env`. |
| **Multer** | Middleware | Middleware for handling `multipart/form-data`, primarily for file uploads. |
| **Cloudinary** | Service | Cloud service for image and video management (storage and optimization). |
| **Nodemon** | Dev Tool | Utility that monitors for changes and automatically restarts the server. |
| **Prettier** | Dev Tool | Opinionated code formatter. |
